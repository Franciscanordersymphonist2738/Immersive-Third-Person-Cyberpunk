# Immersive Third Person Cyberpunk

**Immersive Third Person Cyberpunk** is a camera pack for 2077 on Windows. Over-the-shoulder walk, driving cam, photo mode. CET / redscript. Drop the zip in the mods folder.

## Getting Started
1. Download v1.2.0.
2. Extract `ImmersiveThirdPerson.zip` into the game mods folder.
3. Launch with CET.
4. F4 opens the camera panel.

## FAQ

**First or third?**
This pack is third person. First person stays in the vanilla bind.

**Phantom Liberty?**
Yes. Same CET path.

**Crashes on boot?**
Update redscript / CET, then drop this zip last.

## Requirements
Windows 10/11. Cyberpunk 2077 + CET + redscript.
